Quick start

Generate a labeled log with the simple API.

Choose drift definitions, pass any generator options you need, then write a log.

import rheon

drifts = [{"perspective": "data", "subtype": "numeric", "drift_type": "sudden"}]

rheon.generate_log(
    drifts,
    "data/example/data_001.xes",
    num_traces=100,
    global_seed=7,
)

Installation

Get the runtime and dependencies in place.

Prerequisites

  • Python 3.10 or newer
  • uv package manager

Set up

Clone the repository and let uv resolve dependencies on first run:

git clone <repo-url> rheon
cd rheon
uv sync

Verify

Run a quick sanity check by generating a tiny log:

uv run python scripts/generate_control_flow_log.py

Drift types

How the change is shaped over time.

Type Behavior Optional parameters
sudden Hard switch at change_point. None.
gradual_linear / gradual Old and new behavior overlap. Probability of new behavior rises linearly. Transition width uses the gradual_overlap_fraction option, default 0.10.
gradual_exponential Overlapping behaviors. New behavior starts slowly and rises faster near the end. Transition width uses the gradual_overlap_fraction option, default 0.10.
incremental Creates intermediate versions and moves through them across the transition window. num_versions: integer, clamped to 3–5. Default: random 3–5.
recurring Alternates between old and new behavior for a period, then settles on the new behavior. period_days: length of one phase. Default uses the recurring_period_fraction option, 0.20.

Drift perspectives

What part of the process changes.

A drift perspective describes the process dimension affected by a drift. Combine it with a drift_type to choose the time shape, then choose a subtype to define the concrete mechanism.

Perspective What changes Subtypes Generated evidence
control_flow Activities, ordering, branching, loops, and concurrency in the process tree. tree_mutation Changed variants, activity structure, and process-tree metadata.
resource Who performs work, how work is distributed, service speed, pool size, and handovers. reassignment, workload_distribution, service_time, pool_size, handover org:resource, org:role, event durations, and resource drift metadata.
inter_case How cases enter the log, how arrivals cluster, case mix, and case overlap. arrival_rate, burstiness, case_mix, concurrency Case start timestamps, case:case_type, and concurrency-sensitive timing patterns.
data Case-level attributes independent of the route through the process. numeric, categorical case:amount, case:region, and attribute distribution metadata.

Control flow

Drift subtypes that mutate the process tree.

Subtype Effect Optional parameters
tree_mutation Mutates the process tree by adding, deleting, or moving activities and swapping operators. change_proportion: float 0.0–1.0, default 0.25.
intensity: alias used when change_proportion is absent.

Resource

Drift subtypes that change resource behavior.

Subtype Effect Optional parameters
reassignment Changes the dominant resource for selected activities while keeping the 80/20 dominance shape. activities: list of activity labels or "all". Default: "all".
workload_distribution Changes event counts per resource by skewing activity-resource assignment probabilities. resources: list of active resources or "all". Listed resources receive 70% of event assignment probability.
service_time Changes processing speed for selected resources. Multipliers above 1.0 are slower, below 1.0 faster. resources: list of resources or "all".
pool_size Shrinks or expands the active resource pool. Inactive resources are not assigned work. None.
handover Rewires one source resource to a different dominant next-resource target. None.

Inter case

Drift subtypes that change how cases enter and overlap.

Subtype Effect Optional parameters
arrival_rate Changes mean inter-arrival time. Cases arrive faster or slower. None.
burstiness Switches arrival shape between exponential and bursty bimodal-Pareto behavior. None.
case_mix Changes the distribution of case:case_type. None.
concurrency Records a concurrency drift marker. Concurrency is emergent from arrivals and event durations. None.

Data

Drift subtypes that change case-level attributes.

Subtype Effect Optional parameters
numeric Changes the mean and standard deviation of case:amount. None.
categorical Changes the distribution of case:region. None.

Drift parameters

Required and optional keys in a DRIFTS entry.

Each entry in DRIFTS is a Python dictionary.

Parameter Required Applies to Description
subtype Yes All drifts One of the subtype names listed in the subtype pages.
drift_type Yes All drifts sudden, gradual_linear, gradual_exponential, incremental, or recurring.
perspective Yes All drifts control_flow, resource, inter_case, or data.
change_point No All drifts Fraction of the generated horizon, clamped to 0.05–0.95. 0.5 is the midpoint. If omitted, Rheon places drifts within their perspective-specific slots.
num_versions No drift_type="incremental" Number of versions, clamped to 3–5. Default: random 3–5.
period_days No drift_type="recurring" Length of one recurrence phase. If omitted, derived from recurring_period_fraction.
change_proportion No tree_mutation Mutation intensity. Useful values: 0.05 subtle, 0.20 medium, 0.50 strong. Default: 0.25.
intensity No tree_mutation Alias for mutation intensity, used only when change_proportion is absent.
activities No Resource reassignment List of activity labels or "all". Default: "all".
resources No workload_distribution, service_time List of resource ids such as ["res_001"], or "all". Default: "all".

Output

XES log and a metadata sidecar.

<output_folder>/<log_name>.xes
<output_folder>/<log_name>.xes.metadata.md

Log columns

event:id, case:concept:name, concept:name, start_timestamp, time:timestamp, event:duration_min, org:resource, org:role, case:case_type, case:amount, case:region

Metadata

Each drift metadata record contains:

drift_id, perspective, subtype, drift_type, change_point_timestamp, overlap_window_start, overlap_window_end, affected_columns, change_details

The XES file stores JSON strings in log attributes: drift_info, config_info, and noise_info.

Examples

Copy-and-edit API calls, editable scripts, and DRIFTS blocks.

Basic API

import rheon

drifts = [{"perspective": "resource", "subtype": "pool_size", "drift_type": "sudden"}]

generated = rheon.generate_log(
    drifts,
    "data/resource/resource_001.xes",
    num_traces=100,
    global_seed=7,
)

Editable scripts

generate_control_flow_log.py

Changes the process tree. Use for activity, variant, and ordering drift.

generate_resource_log.py

Changes resource assignment, workload, handover, pool size, or service speed.

generate_inter_case_log.py

Changes case arrival behavior, burstiness, case mix, or emergent concurrency.

generate_data_log.py

Changes case-level numeric and categorical attributes.

generate_multi_perspective_log.py

Combines perspectives. Add a perspective key to each drift entry.

validate_log.py

Validates a generated XES file and prints its drift metadata summary.

Each script now calls rheon.generate_log() directly inside its loop, so you can edit the same pattern for your own scenarios.

Explicit drift blocks

DRIFTS = [
    {"perspective": "control_flow", "subtype": "tree_mutation", "drift_type": "sudden", "change_proportion": 0.2},
    {"perspective": "resource", "subtype": "reassignment", "drift_type": "gradual_linear", "activities": ["a", "c"]},
    {"perspective": "resource", "subtype": "workload_distribution", "drift_type": "sudden", "resources": ["res_001", "res_003"]},
    {"perspective": "resource", "subtype": "service_time", "drift_type": "incremental", "resources": "all", "num_versions": 4},
]
